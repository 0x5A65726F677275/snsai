## What "0 competition" actually means

It does **not** mean an empty niche. Empty niches usually have no search demand.

It means **weak supply**:

| Signal | Pass | Fail |
|--------|------|------|
| Top 10 channel size | 6+ results under 100K subs | Wall of 1M+ channels |
| Freshness | 5+ ranking videos older than 12 months | All results from last 60 days by big channels |
| Packaging | Weak thumbnails, generic titles, no chapters | MrBeast-grade packaging already winning |
| Volume vs quality | Search autocomplete exists, answers are thin | No autocomplete AND no related searches |
| Repeatability | You can write 10 more titles in the same lane | One-off novelty with no series depth |

**Operator rule:** beat stale, poorly packaged videos — do not hunt a desert.

YouTube 2026 still monetizes faceless + AI-assisted channels. It punishes **low-effort mass-produced slop**. Human research + human POV + AI production = allowed. Script + TTS + random stock with no editorial = dead.

Always check **Altered or synthetic content** on upload.

## Daily loop (45–75 minutes)

Run this every morning **before** you generate anything.

### 1) Seed + modifiers (8 min)

Type a seed from the account niche into YouTube search. Do **not** publish the seed. Publish the long-tail.

**Seeds (this account):**
- Instagram AI workflow
- MCP agent Instagram
- daily trend report creators
- AI slop Instagram
- 0 competition YouTube keywords

**Modifiers (add 2–3):**
- `how to` + `2026`
- `for Instagram creators` / `for solo founders`
- `without filming` / `without a face`
- `every day` / `in 15 minutes`
- `MCP` / `agent` / `Cursor`

Capture 8–12 autocomplete + "People also search" phrases.

### 2) Weak-supply scan (7 min)

For the top 3 candidates, open YouTube search (not Google). Score the first 10 videos:

```
0-COMP SCORE = Demand(0-20) + WeakSupply(0-25) + PackagingGap(0-20) + NicheFit(0-20) + SeriesDepth(0-15)
```

Ship only **80+**. If nothing hits 80, go to Lane B/C in the keyword bank — do not force a saturated listicle.

### 3) Lock one keyword (2 min)

One **search title** (long-form, 8–12 min) + one **Shorts hook** cut from the first 45 seconds.

Title formula for this brand:

`[Specific claim + number] + [0-comp / operator verb] + (2026)`

Example: `I Post a 0-Competition YouTube Video Every Day With This AI Loop (2026)`

### 4) Human script, AI production (20–35 min)

- Write the hook and payoff yourself. AI may draft the middle.
- Use the **Editorial Motion Graphics** faceless style (dark / violet / cyan) — not generic stock.
- Voice: calm operator, not hype bro.
- On-screen text: English only, 3–6 words per card.
- Thumbnail: 16:9, 3–5 word headline, people-free dashboard unless a real face is supplied.

Higgsfield path:
- Long-form / narrated explainer → `faceless-channel-video` workflow
- Thumbnail → `youtube-thumbnail-generator` (16:9)
- Daily Short → `seedance_2_5` 9:16, 12–20s, `generate_audio: true`

### 5) SEO pack + publish (10 min)

| Field | Rule |
|-------|------|
| Title | Primary keyword in first 50 characters |
| Description first 2 lines | Keyword + promise (shows before Show more) |
| Chapters | Every 45–90s |
| Tags | 8–12 English phrases, mix seed + long-tail |
| End screen | Subscribe + next video in the same lane |
| Shorts | Same hook, 9:16, pin comment with the long-form link |
| Disclosure | Altered / synthetic content = Yes |

**Upload times (America/New_York):**
- Long-form search video: 10:00
- Shorts browse: 12:00 and/or 18:00
- Instagram 1:1 carousel of the same lesson: 19:10 (existing publish task)

### 6) Log (5 min)

Write results back to `trends/registry.json` and `analytics/performance-log.json`:

- Search impressions / CTR / AVD (average view duration)
- Shorts views / % viewed
- Subs gained
- Which filter scores predicted the win

Double down on lanes with CTR > 6% and AVD > 40%. Kill lanes that get impressions but no clicks (thumbnail/title), or clicks but no watch time (hook/pacing).

## 5-filter card (memorize)

A keyword ships only if **4 of 5** are true:

1. **Autocomplete exists** — a human is already typing it
2. **Weak supply** — small or stale channels occupy the first page
3. **Packaging gap** — you can win the click with a sharper title + thumb
4. **Niche fit** — Instagram / AI operator / trend intelligence
5. **Ten more titles** — it is a lane, not a one-off

If 3 or fewer: skip. Find another modifier.
